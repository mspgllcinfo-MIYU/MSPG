# poicat (Android)

`com.mspg.poicat` のAndroidプロジェクトです。

## 猫AI = 完全オフラインの「記憶する猫」

「猫AI」画面は、OpenAI/Cloudflare/Firebaseへの通信を一切行いません。
すべて端末内（Room Database）で完結する、ルールベースのスケジュール
アシスタントです。

- 従量課金・追加課金は一切発生しません
- インターネット接続がなくても動作します
- 会話履歴（表示用）は引き続き端末内JSONに保存（`ChatRepository`）
- 予定・タスク・メモの実データはRoom Database（`cat_events`テーブル）に保存

### できること

| 入力例 | 動作 |
|---|---|
| `来週の水曜、出張ね` | 予定として記憶し「覚えたにゃ」と返す |
| `明日、通院` | 同上 |
| `来週の出張いつ？` | 記憶した予定から検索し「出張は来週の水曜日だにゃ」のように回答 |
| `明日の予定は？` | 該当日の予定を回答（なければ「明日の予定はまだ入ってないにゃ」） |
| `次の通院いつ？` | キーワード検索して直近の該当予定を回答 |
| 日付を含まない自由文 | メモとして記憶し「覚えたにゃ」と返す |

日時の解析は `brain/DateTimeParser.kt` にある簡易ルールベースの
正規表現マッチングです（今日/明日/明後日、来週・今週の曜日、
「N日後」「N週間後」「M月D日」「N時」など）。自然文を完全に理解する
AIではありません。

予定・メモ・ポイの登録／質問は、多少の言い回しの違い（例：
「明日病院」「明日は病院」「明日病院だから覚えといて」／
「駐車場1234覚えといて」「1234ってメモ」／「牛乳買う」
「牛乳買わなきゃ」「牛乳忘れないように」）を`brain/CatBrain.kt`の
キーワード・接尾辞マッチングで吸収します。有料AI APIは使用せず、
すべて端末内のルールベース処理です。

### 通知（リマインダー）

`notify/ReminderWorker.kt` が **WorkManager** で15分おきに実行され、
以下のタイミングで端末通知を出します。

- 予定の前日: 「明日〇〇だよー」
- 予定の1時間前: 「あと1時間で〇〇だよ」

正確な時刻起動が必要な `AlarmManager` の完全代替ではなく、15分間隔の
バックグラウンドチェックのため、通知タイミングには最大15分程度の
ずれが生じます（バッテリー消費と実装のシンプルさを優先したトレードオフです）。

Android 13以降では通知の許可（`POST_NOTIFICATIONS`）をアプリ起動時に
リクエストします。拒否された場合、記憶・検索機能は使えますが通知は
届きません。

### カレンダー

猫AIと**同じ `cat_events` テーブル**を読み書きする月表示カレンダーです。

- 猫AIで登録した予定は自動的にカレンダーに反映されます（データが共通のため）
- 日付をタップするとその日の予定一覧が表示されます
- 「＋ 追加」から予定の追加、一覧タップで編集、✕で削除ができます
- カレンダーから追加・編集した予定も、猫AIから質問して回答を得られます
- 同じタイトル・同じ日時の予定は重複登録されません（自動的に既存の予定を再利用します）

### メモ

猫AIに覚えさせた日付なしのメモ（`cat_events`テーブルで`dateTime`が空のもの）
を一覧表示します。

- 猫AIに「牛乳を買う」のように話しかけると自動でメモ画面にも反映されます
- 「〇〇をメモして」「〇〇って覚えておいて」のように明示的に頼むと、
  「〇〇」の部分だけを抜き出してメモとして保存し「メモしたにゃ」と返します
- 「＋ 追加」から新規メモ、一覧タップで編集、✕で削除ができます
- メモ画面から追加・編集した内容も、猫AIにキーワードで聞けば
  「〇〇って覚えてるにゃ」のように答えます（「駐車場の番号なんだっけ？」→
  「1234だにゃ」のように、メモの続きの部分だけを答えられる場合はそちらを優先）
- メモを削除すると、猫AIの検索対象からも同時に外れます（同じテーブルを
  参照しているため）

### ポイ（タスク管理）

同じ`cat_events`テーブルに`isTask = true`として保存される、シンプルな
やること・タスクリストです。予定/メモとはテーブル上で区別されるため、
カレンダーやメモの一覧には表示されません。

- 「＋ 追加」でタスクを登録（期限は任意で設定可能）
- チェックボックスで完了/未完了を切り替え
- 一覧タップで編集、✕で削除
- 猫AIに「牛乳買うの忘れないで」「今日ゴミ出しやる」「9月10日までに書類を出す」の
  ように話しかけると、自動的にポイのタスクとして登録されます（「ポイに入れたにゃ」）
- 猫AIに「今日やることは？」「残ってるタスクは？」「ポイに何が入ってる？」
  「明日までのタスクは？」と聞くと、未完了タスクから答えます
- 猫AIに「牛乳買ったよ」「牛乳のタスク終わった」のように話しかけると、
  該当するタスクが完了扱いになります
- ポイ画面で削除・完了にしたタスクは、猫AIの検索対象からも同時に外れます

### ホーム

猫ちゃんが主役のダッシュボードです。編集機能は持たず、詳細な操作は
カレンダー/メモ/ポイの各画面で行います。

- **動く猫ちゃん**（`AnimatedCat.kt`）：見た目はコードで描画せず、
  用意した5枚の透過PNG画像（`res/drawable-nodpi/cat_normal.png`ほか
  通常/まばたき/左を見る/右を見る/タップ時）をそのまま画像素材として
  `Image`で表示しています。「アニメーション」は表示するPNGの切り替えと、
  ごく軽い`Modifier.graphicsLayer`（数px程度の上下の揺れ・わずかな
  傾き・タップ時の一瞬の拡大）のみで、キャラクターの形自体は一切
  変形させていません。タップすると一瞬タップ用の画像に切り替わってから、
  猫AIタブへ移動します。
- 猫ちゃんの吹き出し：保存されている今日の予定・未完了ポイ・次の予定・
  最近のメモから、状況に応じて一言をにゃ語尾で表示します
  （例：「今日は病院だにゃ」「ポイが2個残ってるにゃ」「おはようにゃ」）
- 今日の予定 → タップでカレンダーへ
- 次の予定 → タップでカレンダーへ
- 未完了のポイ → タップでポイ画面へ
- 最近のメモ（あれば表示） → タップでメモ画面へ

猫AI ⇔ カレンダー/メモ/ポイの連携データをそのまま読み取って表示するだけなので、
データベースの構造は変更していません（アップデートしてもデータは消えません）。

## ビルド（GitHub Actions）

Firebase/Cloudflareへの依存がなくなったため、**GitHubシークレットの設定は不要**です。
`android/**` にpushすると自動的にGitHub Actionsが debug APK をビルドし、
Actionsの実行結果ページからダウンロードできます。

`android/debug.keystore` はどのビルドでも同じ署名になるようリポジトリに
コミットしています（デバッグ用の鍵で、パスワードも既定値の`android`固定
のため機密情報ではありません）。これがないと、GitHub Actionsの実行のたびに
異なる署名鍵でAPKがビルドされてしまい、新しいAPKをインストールするたびに
Androidが「別のアプリ」とみなして端末内データを消してしまいます。
